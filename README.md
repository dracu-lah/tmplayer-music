# TMPlayer Music

A music player for the audio files already in your own Telegram chats. FLAC, MP3 and more, synced
lyrics, playlists, a cache you control, and a TV app and remote control to follow. Unofficial, not
affiliated with Telegram. The sibling of [TMPlayer](https://github.com/dracu-lah/TMPlayer), the video
player.

**Status:** planning. No code yet. See [plan/PLAN.md](plan/PLAN.md).

Home page (planned): music.tmplayer.org

## Working on it

Read [AGENTS.md](AGENTS.md) first. The plan is in [plan/](plan/): the research, the TV and Cast plan, the
build order and which TMPlayer files this project reuses.
